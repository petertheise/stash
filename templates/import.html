Columns

Only name is required. Column names are matched case-insensitively.

nameItem name
quantityWhole number, defaults to 1
locationPath with slashes, like Home / Garage / Shelf 2. Missing locations are created.
labelsComma separated. New labels are created.
description, serial, model, manufacturer, purchase_from, notesFree text
purchase_priceNumber, dollar signs and commas are fine
purchase_date, warranty_untilYYYY-MM-DD or MM/DD/YYYY
warranty_notesFree text
lifetime_warranty, archivedyes or no
idStash's own item number, from an export. With the box above ticked, that item is updated; only the columns in your file change.
field:AnythingCustom field, for example field:Color

Export CSV gives you the same layout back, so you can edit it in a spreadsheet and re-import it safely. A Homebox or spreadsheet export needs only the column names changed. For a full backup with photos and documents, use Export everything (zip).
